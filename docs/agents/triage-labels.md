# 分诊标签

| Matt Skills 中的标签 | 当前跟踪器中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估该 Issue |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以交给 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要由人工实施 |
| `wontfix` | `wontfix` | 已决定不处理 |

当技能引用某个标准分诊角色时，使用本表中对应的标签。
